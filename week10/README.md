배운 내용 정리
문자 처리 함수(ctype.h)는 isalpha, isupper, islower, isdigit, isalnum, isxdigit, ispunct, isprint, iscntrl 등이 있고, 조건을 만족하면 0이 아닌 값, 만족하지 않으면 0을 반환한다. 조건 연산자 ? : 와 함께 써서 결과에 따라 "예" 또는 "아니요"를 출력했다.
문자열 처리 함수(string.h)에서 strlen은 널 문자를 제외한 문자열의 길이를 반환하고, strcpy는 문자열을 널 문자까지 복사한다. strncpy는 앞의 n개 문자만 복사하고 널 문자를 자동으로 붙이지 않기 때문에 str3[n] = '\0'처럼 직접 널 문자를 추가해야 한다.
구조체(struct)는 서로 다른 자료형의 데이터를 하나로 묶는 자료형이다. 구조체 변수의 멤버는 . 연산자로 접근하며, 문자열 멤버에는 = 로 대입할 수 없어서 strcpy를 사용했다.
구조체 포인터로 다른 구조체의 주소를 저장하면 그 구조체의 데이터를 참조할 수 있고, 포인터를 통해 멤버에 접근할 때는 -> 연산자를 사용한다. 문자열 입력은 공백까지 읽을 수 있는 fgets를 사용했다.
