C언어의 반복문과 조건문을 활용한 별 출력과 정렬 방법을 배웠다.
중첩 반복문을 사용해서 입력한 줄 수만큼 별을 출력하는 방법을 연습했고, for문의 초기식, 조건식, 증감식이 어떻게 반복되는지도 확인했다. 
또한 if문을 이용해 조건에 따라 다른 결과를 출력하는 방법을 배웠다.
정렬에서는 선택 정렬과 삽입 정렬의 기본적인 원리를 배우고 직접 코드를 작성해 보았다.
선택 정렬은 가장 작은 값을 찾아 현재 위치의 값과 바꾸는 방식이고, 
삽입 정렬은 앞에서부터 정렬된 부분을 만들면서 새로운 값을 알맞은 위치에 삽입하는 방식이라는 차이를 알게 되었다.
